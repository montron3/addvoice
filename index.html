📖 Guida passo passo

Come aggiungere la traccia tradotta al tuo video finale:

  • 1 Carica il tuo video/audio — il sistema estrae l'audio originale (scomposizione automatica con FFmpeg.wasm).
  • 2 Inserisci le API keys: Whisper (trascrizione), DeepSeek (traduzione contestuale) e ElevenLabs (sintesi vocale).
  • 3 Clicca "Traduci e genera traccia audio". Il sistema:
    • ✓ Scompone il file → estrae l'audio
    • ✓ Trascrive con Whisper API
    • ✓ Traduce con DeepSeek nella lingua scelta
    • ✓ Genera voce tradotta con ElevenLabs (gestione chunking)
    • ✓ Ricompone il video sostituendo la traccia audio originale con la nuova voce tradotta
  • 4 Scarica il risultato — ottieni il video finale con la nuova traccia, pronto per YouTube! Puoi anche scaricare solo l'audio tradotto.
  • 5 Suggerimento: Se vuoi mantenere audio originale come seconda traccia, usa software esterno; il nostro tool la sostituisce per creare il doppiaggio pulito.
💡 Nota tecnica

Viene utilizzato FFmpeg.wasm per decomposizione (estrazione audio) e ricomposizione (mux video + nuovo audio). Le chiamate API avvengono lato client, le tue chiavi rimangono nel browser.

🎯 Per video lunghi, assicurati che i chunk audio non superino i limiti di ElevenLabs (gestito automaticamente).
